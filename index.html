PROBLEM 01

Transmission Through a Finite Barrier — E>V_0

Derive Equation (2.37) and discuss the transmission coefficient.

Question Statement

Derive Equation (2.37) and plot the transmission coefficient T as a function of the incident-particle energy E. Comment on the behavior of T.

Consider

\[ V(x)= \begin{cases} 0,&x<0\\ V_0,&0\le x\le a\\ 0,&x>a \end{cases} \]

for \[ E>V_0. \]

Concept

This is a finite potential barrier. Since \[ E>V_0, \] the particle has positive kinetic energy in all three regions, so the wave functions are oscillatory everywhere.

\[ k=\frac{\sqrt{2mE}}{\hbar}, \qquad q=\frac{\sqrt{2m(E-V_0)}}{\hbar}. \]

Complete Step-by-Step Solution

Step 1 — Region I:

\[ \boxed{\psi_1=Ae^{ikx}+Be^{-ikx}} \]

Ae^{ikx} is the incident wave and Be^{-ikx} is the reflected wave.

Step 2 — Region II:

\[ \boxed{\psi_2=Ce^{iqx}+De^{-iqx}} \]

Step 3 — Region III:

\[ \boxed{\psi_3=Fe^{ikx}} \]

There is no wave incident from +\infty.

Step 4 — Boundary conditions at x=0:

\[ A+B=C+D \tag{1} \]
\[ ik(A-B)=iq(C-D) \] \boxed{k(A-B)=q(C-D)} \tag{2} 

Step 5 — Boundary conditions at x=a:

\[ Ce^{iqa}+De^{-iqa}=Fe^{ika} \tag{3} \]
\[ q(Ce^{iqa}-De^{-iqa}) = kFe^{ika}. \tag{4} \]

Solving these equations gives

\[ \frac FA = \frac{e^{-ika}} {\cos(qa) -i\left(\frac{k^2+q^2}{2kq}\right)\sin(qa)}. \]

Since the potential is the same on both sides, the transmission coefficient is

\[ T= \left|\frac FA\right|^2. \]

Therefore

\[ T= \frac{1} {\cos^2(qa)+ \left(\frac{k^2+q^2}{2kq}\right)^2 \sin^2(qa)}. \]

Using

\[ k^2=\frac{2mE}{\hbar^2}, \qquad q^2=\frac{2m(E-V_0)}{\hbar^2}, \]

we obtain

\[ \frac{k^2+q^2}{2kq} = \frac{2E-V_0} {2\sqrt{E(E-V_0)}}. \]

Hence

\[ \boxed{ T= \left[ 1+ \frac{V_0^2} {4E(E-V_0)} \sin^2(qa) \right]^{-1} } \]
\[ \boxed{ q=\frac{\sqrt{2m(E-V_0)}}{\hbar} } \]

Behavior of T

Resonance:

\[ qa=n\pi \] \[ \sin^2(qa)=0 \] \[ \boxed{T=1} \]

The corresponding resonance energies are

\[ \boxed{ E_n= V_0+ \frac{n^2\pi^2\hbar^2}{2ma^2} } \]

High-energy limit:

\[ E\gg V_0 \quad\Rightarrow\quad \boxed{T\rightarrow1}. \]

The transmission coefficient oscillates because of quantum interference inside the barrier.

Final Answer
\[ \boxed{ T= \left[ 1+ \frac{V_0^2} {4E(E-V_0)} \sin^2(qa) \right]^{-1} } \]
⚛ Physical Interpretation

Classically, a particle with E>V_0 crosses the barrier. Quantum mechanically, partial reflection occurs at both boundaries. The reflected waves interfere with each other, producing resonant transmission. At resonance, \[ \boxed{T=1}. \]

PROBLEM 03

Finite Attractive Square Well

Determine all coefficients in terms of one common coefficient.

Question Statement

Solve the Schrödinger equation for

\[ V(x)= \begin{cases} 0,&x<0\\ -V_0,&0a \end{cases} \]

where V_0>0, for E>0. Particles are incident from x=-\infty.

Concept

This is a finite attractive square well. Because V=-V_0, the particle has greater kinetic energy inside the well.

\[ \boxed{ k=\frac{\sqrt{2mE}}{\hbar} } \]
\[ \boxed{ q=\frac{\sqrt{2m(E+V_0)}}{\hbar} } \]

Therefore \[ q>k. \]

Complete Step-by-Step Solution

Region I:

\[ \boxed{ \psi_1=Ae^{ikx}+Be^{-ikx} } \]

Region II:

\[ \boxed{ \psi_2=Ce^{iqx}+De^{-iqx} } \]

Region III:

\[ \boxed{ \psi_3=Fe^{ikx} } \]

At x=0:

\[ A+B=C+D \tag{1} \]
\[ k(A-B)=q(C-D) \tag{2} \]

At x=a:

\[ Ce^{iqa}+De^{-iqa}=Fe^{ika} \tag{3} \]
\[ q(Ce^{iqa}-De^{-iqa}) = kFe^{ika}. \tag{4} \]

Choose F=F_0. Solving equations (3) and (4):

\[ \boxed{ C= F_0e^{i(k-q)a} \frac{k+q}{2q} } \]
\[ \boxed{ D= F_0e^{i(k+q)a} \frac{q-k}{2q} } \]

Using the conditions at x=0:

\[ \boxed{ A= F_0e^{ika} \left[ \cos(qa) -i\frac{k^2+q^2}{2kq}\sin(qa) \right] } \]
\[ \boxed{ B= iF_0e^{ika} \frac{q^2-k^2}{2kq}\sin(qa) } \]

Thus all coefficients are written in terms of F_0:

\[ \boxed{ \begin{aligned} A&=F_0e^{ika} \left[ \cos qa-i\frac{k^2+q^2}{2kq}\sin qa \right],\\[2mm] B&=iF_0e^{ika} \frac{q^2-k^2}{2kq}\sin qa,\\[2mm] C&=F_0e^{i(k-q)a}\frac{k+q}{2q},\\[2mm] D&=F_0e^{i(k+q)a}\frac{q-k}{2q},\\[2mm] F&=F_0. \end{aligned} } \]
Final Answer

The five coefficients A,B,C,D,F are completely determined up to the arbitrary common amplitude F_0.

⚛ Physical Interpretation

Since q>k, the particle has a shorter de Broglie wavelength inside the attractive well. Abrupt changes of potential at the two boundaries cause both reflection and transmission.

\[ V(x)= \begin{cases} \infty,&x<0\\ \dfrac12kx^2,&x>0 \end{cases} \]

Concept

\[ \boxed{ E_n=\hbar\omega \left(n+\frac12\right) } \]

with n=0,1,2,\ldots.

The infinite wall at x=0 requires

\[ \boxed{\psi(0)=0}. \]

Complete Solution

The full oscillator wave functions have definite parity.

For even n, \[ \psi_n(0)\neq0 \] in general, so the infinite-wall condition is not satisfied.

For odd n, \[ \psi_n(-x)=-\psi_n(x) \] and therefore

\[ \boxed{\psi_n(0)=0}. \]

Thus only \[ n=1,3,5,\ldots \] survive.

Write \[ n=2r+1. \] Then

\[ E_r= \hbar\omega \left(2r+1+\frac12\right) \]
\[ \boxed{ E_r= \left(2r+\frac32\right)\hbar\omega } \]

The first levels are

\[ \boxed{ \frac32\hbar\omega,\quad \frac72\hbar\omega,\quad \frac{11}{2}\hbar\omega,\quad \frac{15}{2}\hbar\omega,\ldots } \]

For x>0, the normalized half-oscillator functions are

\[ \boxed{ \psi_r^{(\mathrm{half})}(x) = \sqrt2\,\psi_{2r+1}^{(\mathrm{full})}(x) } \]

and \[ \psi(x)=0 \] for x\le0.

PROBLEM 06

Probability Beyond the Classical Turning Points

Question Statement

For the ground state and first two excited states of the one-dimensional simple harmonic oscillator, find the probability that the particle lies beyond the classical turning points.

Concept

\[ E_n= \hbar\omega \left(n+\frac12\right) \]

The classical turning point is determined from

\[ E_n= \frac12m\omega^2x_t^2. \]
Therefore

\[ \boxed{ x_t= \sqrt{\frac{2E_n}{m\omega^2}} = \frac{\sqrt{2n+1}}{\alpha} } \]

where \[ \alpha=\sqrt{\frac{m\omega}{\hbar}}. \]

With \[ u=\alpha x, \] the turning point is

\[ u_t=\sqrt{2n+1}. \]

Ground State n=0

\[ \psi_0= \frac{\alpha^{1/2}}{\pi^{1/4}} e^{-\alpha^2x^2/2}. \]

The turning point is u_t=1. Therefore

\[ P_0 = \frac2{\sqrt\pi} \int_1^\infty e^{-u^2}\,du. \]
\[ \boxed{ P_0=\operatorname{erfc}(1)=0.1573 } \]
\[ \boxed{P_0\approx15.73\%} \]

First Excited State n=1

\[ \psi_1(u) = \frac{\sqrt2}{\pi^{1/4}} u e^{-u^2/2}. \]

The turning point is \[ u_t=\sqrt3. \]

\[ P_1 = 2\int_{\sqrt3}^{\infty} \frac{2u^2}{\sqrt\pi}e^{-u^2}\,du. \]
\[ \boxed{ P_1=0.1116 } \]
\[ \boxed{ P_1\approx11.16\% } \]

Second Excited State n=2

\[ H_2(u)=4u^2-2. \]
\[ |\psi_2(u)|^2 = \frac{1}{8\sqrt\pi} (4u^2-2)^2e^{-u^2}. \]

The turning point is \[ u_t=\sqrt5. \]

\[ P_2= 2\int_{\sqrt5}^{\infty} |\psi_2(u)|^2du. \]
\[ \boxed{ P_2=0.09507 } \]
\[ \boxed{ P_2\approx9.51\% } \]

Final Results

State Turning point Probability outside

n=1 \sqrt3/\alpha 11.16%

⚛ Physical Interpretation

Classically, the particle cannot exist beyond x_t. Quantum mechanically the wave function extends into the classically forbidden region. Thus there is a nonzero probability outside the classical region.

PROBLEM 07

Ground-State Uncertainty of the Harmonic Oscillator

Question Statement

For the ground state of the one-dimensional harmonic oscillator, find

(a) \langle x\rangle and \langle x^2\rangle,

(b) \Delta x,

(c) \langle p_x\rangle and \langle p_x^2\rangle,

(d) \Delta p_x and \Delta x\Delta p_x.

Concept

\[ \boxed{ \psi_0(x) = \left( \frac{\alpha}{\sqrt\pi} \right)^{1/2} e^{-\alpha^2x^2/2} } \]
\[ \boxed{ \alpha=\sqrt{\frac{m\omega}{\hbar}} } \]

Complete Solution — (a)

The expectation value is

\[ \langle x\rangle = \int_{-\infty}^{\infty} \psi_0^*x\psi_0\,dx. \]

Since |\psi_0|^2 is even and x is odd, the integrand is odd. Therefore

\[ \boxed{ \langle x\rangle=0. } \]

For x^2:

\[ \langle x^2\rangle = \int_{-\infty}^{\infty} x^2|\psi_0|^2dx. \]

The Gaussian integral gives

\[ \boxed{ \langle x^2\rangle = \frac{1}{2\alpha^2} = \frac{\hbar}{2m\omega}. } \]

Complete Solution — (b)

\[ \Delta x = \sqrt{ \langle x^2\rangle - \langle x\rangle^2 }. \]

Since \langle x\rangle=0,

\[ \boxed{ \Delta x= \sqrt{\frac{\hbar}{2m\omega}}. } \]

Complete Solution — (c)

The momentum operator is

\[ \boxed{ \hat p_x=-i\hbar\frac{d}{dx}. } \]

The ground state is real and symmetric, hence

\[ \boxed{ \langle p_x\rangle=0. } \]

The ground-state energy is

\[ E_0=\frac12\hbar\omega. \]

The potential energy is

\[ \langle V\rangle = \frac12m\omega^2\langle x^2\rangle. \]

Substituting \langle x^2\rangle:

\[ \langle V\rangle = \frac12m\omega^2 \frac{\hbar}{2m\omega} = \frac14\hbar\omega. \]

Therefore

\[ \langle K\rangle = E_0-\langle V\rangle = \frac14\hbar\omega. \]

Since

\[ K=\frac{p_x^2}{2m}, \]

we obtain

\[ \boxed{ \langle p_x^2\rangle = \frac12m\hbar\omega. } \]

Complete Solution — (d)

\[ \Delta p_x = \sqrt{ \langle p_x^2\rangle - \langle p_x\rangle^2 }. \]

Since \langle p_x\rangle=0:

\[ \boxed{ \Delta p_x = \sqrt{\frac12m\hbar\omega}. } \]

Therefore

\[ \Delta x\Delta p_x = \sqrt{\frac{\hbar}{2m\omega}} \sqrt{\frac{m\hbar\omega}{2}}. \]
\[ \boxed{ \Delta x\Delta p_x=\frac{\hbar}{2}. } \]
Final Answer
\[ \boxed{ \langle x\rangle=0 } \] \[ \boxed{ \langle x^2\rangle=\frac{\hbar}{2m\omega} } \] \[ \boxed{ \Delta x= \sqrt{\frac{\hbar}{2m\omega}} } \] \[ \boxed{ \langle p_x\rangle=0 } \] \[ \boxed{ \langle p_x^2\rangle= \frac12m\hbar\omega } \] \[ \boxed{ \Delta p_x= \sqrt{\frac12m\hbar\omega} } \] \[ \boxed{ \Delta x\Delta p_x=\frac{\hbar}{2} } \]
⚛ Physical Interpretation

The Gaussian ground-state wave packet exactly reaches the minimum allowed uncertainty:

\[ \boxed{ \Delta x\Delta p_x=\frac{\hbar}{2} } \]

Therefore it is called a minimum-uncertainty wave packet.

\[ \frac{\partial^2\psi}{\partial x^2}=YZX'' \] \frac{\partial^2\psi}{\partial y^2}=XZY''  \[ \frac{\partial^2\psi}{\partial z^2}=XYZ''. \]

Substitute:

\[ -\frac{\hbar^2}{2m} \left( YZX''+XZY''+XYZ'' \right) =EXYZ. \]

Divide by XYZ:

\[ -\frac{\hbar^2}{2m} \left[ \frac{X''}{X} + \frac{Y''}{Y} + \frac{Z''}{Z} \right] =E. \]

Thus each term must be a constant. Write

\[ \frac{X''}{X}=-k_x^2, \qquad \frac{Y''}{Y}=-k_y^2, \qquad \frac{Z''}{Z}=-k_z^2. \]

Therefore

\[ \boxed{ k_x^2+k_y^2+k_z^2 = \frac{2mE}{\hbar^2}. } \]

For x:

\[ X''+k_x^2X=0. \]

Hence

\[ X=A\sin k_xx+B\cos k_xx. \]

The boundary condition at x=0 gives \[ B=0. \]

At x=a:

\[ \sin(k_xa)=0. \]

Therefore

\[ \boxed{ k_x=\frac{n_x\pi}{a}. } \]

Similarly:

\[ \boxed{ k_y=\frac{n_y\pi}{a}, \qquad k_z=\frac{n_z\pi}{a}. } \]

The normalized wave function is therefore

\[ \boxed{ \psi_{n_xn_yn_z} = \left(\frac2a\right)^{3/2} \sin\frac{n_x\pi x}{a} \sin\frac{n_y\pi y}{a} \sin\frac{n_z\pi z}{a}. } \]

The energy is

\[ \boxed{ E_{n_xn_yn_z} = \frac{\hbar^2\pi^2}{2ma^2} (n_x^2+n_y^2+n_z^2). } \]
⚛ Physical Interpretation

The 3-D problem separates into three independent 1-D infinite-well problems. The total energy is

\[ \boxed{ E=E_x+E_y+E_z. } \]
